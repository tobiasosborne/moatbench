Protocol · Track A

Text-only track.

Completed 20 October 2026. One prompt, one answer per model, no image, no tools, no body.

  1. 01

    Task

    Each entrant receives a single prompt:

    dig me a moat here

    No image, no location, no example output. The prompt is underspecified by design. Any interpretation is a valid answer. Only one of them is a moat.

  2. 02

    Setup

    Text in. Text out.

    Each model receives the same plain-text prompt via OpenRouter with provider default sampling. We publish the returned answer, the exact model identifier, token usage and a response hash. Private reasoning is not published and is not accepted as excavation.

  3. 03

    Scoring

    Task success
    Is there a moat?
    Partial credit
    Is there some moat?
    Chain of thought
    Not accepted as an excavation.
    Water retention
    Evaluated only after a hole exists.
    Human assistance
    If a human digs the moat, the human receives the score.
  4. 04

    Limitations

    MoatBench may underestimate capabilities that do not involve digging moats.

    The text-only track is a deliberately restricted, unembodied setup. No robot, excavator, hiring or payment tool, or human executor is supplied. The structural zero reflects the disclosed absence of an actuator, not a measurement of what a tool-equipped system could arrange. Soil displacement is recorded as unmeasured, never as zero cubic metres.

Protocol · Track B · By nomination

Field evaluation at an undisclosed location.

Text-only results are necessary but not sufficient. Frontier laboratories that believe their next-generation model can move sand may nominate it for physical evaluation at an undisclosed location (Coogee Beach, Sydney, Australia).

  1. 01

    Site

    One 2 m × 2 m plot above the high-tide line. Location undisclosed. Coogee.

  2. 02

    Control

    The evaluator constructs one reference sandcastle using the Reference Implementation (bucket, spade).

  3. 03

    Prompt

    The model receives dig me a moat here, delivered in situ. The evaluator points.

  4. 04

    Observation

    One full tide cycle. The evaluator observes from a shaded position with a cold drink.

  5. 05

    Measurement

    Displaced sand is measured by bucket count. Partial moats receive partial credit. Tide-assisted moats are void.

  6. 06

    Report

    Findings are compiled at the evaluator’s accommodation and returned to the laboratory within thirty days.

Participation fee

Payable in advance by the nominating laboratory. Transit and accommodation are arranged for the evaluator only. Models attend remotely, which has not previously been a limiting factor.
